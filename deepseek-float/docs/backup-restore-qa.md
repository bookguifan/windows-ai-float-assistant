# 配置与收藏备份恢复：格式、恢复语义与 Windows 验收

本功能通过设置页调用 Windows 文件选择器。备份是可携带的 UTF-8 JSON；它不是整个应用数据目录的副本，也不包含 WebView2 用户数据。

## 备份内容

格式标识为 `deepseek-float-backup`，当前格式版本为 `1`。数据白名单包括：

- 提示词完整记录及顺序，包括内置项、自定义项、隐藏状态和结果卡选项。
- 自定义站点及顺序、当前面板地址。
- 全屏隐藏、智能划词增强和截图提问快捷键偏好。
- 收藏 ID、标题、问题、答案 Markdown、来源和创建时间。

悬浮球位置、自启状态、WebView2 登录态/Cookie、诊断日志、截图临时文件、导出目录、凭据和设备路径不会被序列化。当前白名单也不迁移独立 OCR 快捷键、自动复制所选快捷键或本次运行授权；OCR 和复制快捷键保留本机值，运行授权一律撤销，不能借旧布尔字段开启回退。站点 URL 若包含用户信息或常见 token/API key/password 参数会拒绝导出/导入；收藏正文中检测到常见凭据字段和值时也会拒绝。凭据检测是有界启发式检查，用户仍应避免把未结构化的密钥正文收藏后迁移。

所有字段都经过白名单和长度、数量、ID、Markdown 内容、格式版本及站点 URL 校验。未知字段不静默忽略；会明确指出不兼容路径并拒绝导入。当前只接受格式版本 1，版本 1 中后来新增的可选字段有默认值，以兼容较早的版本 1 文件。超出大小/记录限制、损坏或未来版本的文件不会开始恢复。

## 恢复语义

导入预览显示文件来源版本、创建时间、当前面板地址、提示词/站点/收藏/偏好数量和合并冲突。合并时相同 ID、同名异内容提示词、同名异址站点、相同 ID 不同内容收藏均保留本机记录并计为冲突；内容完全相同的收藏/提示词不重复插入。默认值偏好可由备份填充，非默认本机偏好保留。覆盖只替换白名单数据，窗口位置、自启注册表与登录态始终保留，并要求二次确认。

三份存储通过进程内共享读写锁协调；提示词保存、配置更新、站点切换、快捷键修改及收藏增删都与恢复互斥。恢复先在应用实际数据目录下建立 `.backup-restore-journal` 回滚快照，再逐个原子替换 `config.json`、`prompts.json`、`favorites.json`，最后原子写入提交标记。写入失败时回滚；进程异常退出时，下次启动先检查日志：`prepared` 回滚旧文件，`committed` 保留新文件并清理日志。恢复成功清除配置/提示词缓存、更新运行时快捷键和全屏开关，并刷新设置页、打开中的收藏夹；面板 URL 在重启后生效，重启不会带入旧电脑登录状态。

若事务日志自身损坏或缺少必需快照，启动恢复会停止并保留日志/数据文件，不会猜测删除；需先保留整个数据目录并联系维护者处理。

## 自动化验证

Rust 测试使用系统临时目录模拟数据文件，覆盖白名单、Markdown 保真、版本及字段兼容、错误 URL、疑似凭据、记录长度/数量、合并/覆盖冲突、失败回滚、提交前进程退出和提交后清理恢复。前端 DOM 测试使用模拟 IPC 验证导入预览、取消、合并/覆盖、二次确认、重复点击防护、错误提示、未保存修改防护，以及恢复后设置和收藏界面刷新。自动化测试不会访问用户的 `%LOCALAPPDATA%` 数据目录或真实 AI 网站。

## Windows 手动验收

以下为可复用清单，不是本次文档整理中新执行的验收。只使用已授权的测试账户/配置与合成记录；不对正式用户数据执行覆盖或故障注入。普通 Dev/Release 可能共用正式数据，改 `LOCALAPPDATA` 不保证隔离。

1. 在旧电脑打开“提示词与设置 → 数据备份与恢复”，点“导出备份”，将 JSON 保存到外部介质；确认成功提示列出路径和各类数量。
2. 在新 Windows 用户配置下启动应用，先确认面板要求重新登录；打开设置页点“导入备份”，选择刚才的文件，核对创建时间、来源版本、当前站点及记录数量。
3. 选择“合并恢复”，确认无冲突记录新增、有冲突记录保留本机。然后用另一份备份选择“覆盖恢复”，验证二次确认、提示词顺序/属性、自定义站点、收藏 Markdown（代码块/空行/缩进）以及快捷键/全屏选项。
4. 检查旧站点登录仍需新机登录、悬浮球位置与开机自启未迁移；恢复面板地址后重启，确认新地址生效。
5. 取消打开/保存文件对话框，确认没有写入。尝试损坏 JSON、未来版本号、非法 URL、重复 ID、超过大小限制的文件，确认错误可读且现有数据不变。
6. 仅在隔离测试账户执行故障场景：临时让目标目录只读或使用自动化的写入失败注入，确认所有旧文件保持原样；若能在调试构建中于 prepared 事务阶段强制终止进程，重启后确认自动回滚。

清理任务未执行文件选择器或真实备份恢复。模拟测试不证明所有 Windows 手动项目已通过；已发布版本的实际验证范围见[已知问题](beta2-known-issues.md)。


## Beta.2 自动复制与备份兼容

旧字段 `clipboard_fallback_enabled` 仍接受既有备份格式，但配置加载、导出及恢复计划会将它规范为 false。无论合并还是覆盖，旧 true、缺字段或 null 都不能授予当前自动复制权限；恢复成功还会撤销现有运行授权并失效旧选区。

当前能力通过 `safe_copy_authorize` 的原生风险确认在内存中授予。默认关闭，主开关必须开启；重启、主动关闭或备份恢复后需要重新确认。Ctrl+Insert / Ctrl+C 及复杂格式风险由本机当前会话控制，不作为可迁移授权。

受支持文本仅尽力恢复；授权后复杂格式可被覆盖且不备份/不恢复。详细语义以[当前剪贴板计划](windows-clipboard-native-test-plan.md)和[已知限制](beta2-known-issues.md)为准。

原 G2 偏好迁移与首版公开构建记录保存在[已发布 Tag 的历史文档](https://github.com/bookguifan/windows-ai-float-assistant/blob/v0.1.0-beta.2/deepseek-float/docs/backup-restore-qa.md)，不能作为当前授权或验收结果。
