## 本轮变更

- 测试隔离构建统一配置、日志、诊断、备份和 WebView2 数据根；普通 Release 保持正式 Tauri 路径行为。
- 修复启动 Ready 回调迟到时覆盖用户手动隐藏状态的问题，并补充代次竞争回归。

- 修复主动纯文本剪贴板写入使用有效窗口 owner；进一步增加清空前快照和发布失败后的尽力恢复。Windows 不提供多格式原子回滚，恢复可能不完整并会明确报告。

- Release Rust 构建映射项目和 Cargo 源路径；普通 Release 固定不启用测试隔离、实验剪贴板回退和自动 Ctrl+C 回退。

## Windows 安装与升级草案

目标是 Windows x64 ZIP，不包含 WebView2 Runtime 或 VC++/UCRT 系统组件。需要可用的 WebView2 Runtime 与 Microsoft Visual C++ x64 Runtime；本机检查到的 Runtime 是 `156.0.4314.58`，不代表其他设备的版本要求或兼容性已完成全矩阵验证。

解压完整 ZIP，保留项目许可证、第三方通知、来源/组件清单及源码材料，然后运行 `deepseek-float.exe`。首次启动可能出现未签名程序或 SmartScreen 提示；不要为安装而关闭 Windows 安全保护。升级前正常退出旧实例并保留核心配置与收藏；不要删除 `%LOCALAPPDATA%` 下的应用数据或 WebView2 用户数据。遇到异常应保留日志，不反复清理数据重试。

ZIP 中的 SHA256 用于检测下载/复制差异，不是发布者身份验证或防篡改签名。公开资产不得包含 PDB、构建日志、本机配置、用户数据或测试缓存。
