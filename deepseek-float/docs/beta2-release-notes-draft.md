# Windows AI 悬浮助手 v0.1.0-beta.2

Beta 预发布说明。应用内部版本为 0.1.0。

## 变更

- 修复球窗 Ready 迟到覆盖手动隐藏状态，加强划词工具条异步会话隔离。
- 加强主动剪贴板写入失败后的尽力恢复及备份输入校验。Windows 多格式剪贴板恢复不保证原子性。
- 智能划词优先使用 UIA / 原生选区读取；保留“智能划词增强”和“自动复制回退”两个主从开关。智能划词缺省开启，保留用户已保存的关闭选择；自动复制回退默认关闭，开启须通过本机原生风险确认，仅本次运行有效。
- 自动复制回退可选 Ctrl+Insert（默认）或 Ctrl+C，更换快捷键须重新确认；每次只发送所选一种，不自动换键重试。关闭主开关或回退会撤销授权，重启后须重新授权。
- 截图提问和截图识字可分别设置全局快捷键；识字快捷键默认未设置。点击设置框后按组合键，Esc 取消，Backspace / Delete 关闭该快捷键；冲突时保留原有按键。统一复制快捷键选择框样式。
- 修复 DeepSeek 上传完成后隐藏加载节点导致自动截图识字误报超时的问题。
- 新划词触发的结果卡定位到本次划词附近；流式更新及继续追问保持用户拖动后的位置，并保留屏幕边缘避让。
- 修复自动复制成功后设置页仍残留上次回退失败提示的问题。复杂格式原剪贴板经本次运行风险授权后允许尝试复制，设置显示未备份、未恢复及可能覆盖的警告。
- 球窗附加诊断只在 beta2-isolation 测试模式启用，普通 Release 不注册诊断 IPC。
- 沿用单一 Windows CI 和打包入口；绿色版包含必要许可证、通知及对应源码。

## 使用和已知问题

解压完整 Windows x64 ZIP 后运行 deepseek-float.exe。需要本机 WebView2 Runtime 和 Visual C++ x64 Runtime。升级前退出旧实例并保留用户配置及收藏。程序可能使用已有登录状态；AI 问答发送给配置的服务商。

Issue #2（启动后偶发异常退出）继续开放：https://github.com/bookguifan/windows-ai-float-assistant/issues/2 。尚未确认根因，一次启动成功不代表彻底修复。

WPS PDF 在本次兼容性测试中需手动选择 Ctrl+C，Ctrl+Insert 未取得有效选区；不能据此保证所有 PDF 或桌面应用均受支持。

结果卡定位已完成本机 Dev 验证；多屏不同 DPI 尚未完成实机兼容验证。最终普通 Release 的验收结果另行确认，不以 Dev 通过代替。

通过系统托盘菜单“退出助手”正常退出。智能划词增强可在设置中开关；需要兼容回退时，开启自动复制并确认风险，根据目标应用选择 Ctrl+Insert 或 Ctrl+C。不支持的软件可先手动复制，再通过面板输入问题。遇到问题请在仓库 Issues 提供系统和应用版本、复现步骤及脱敏截图，勿附账号凭据或私人剪贴板内容。

## 剪贴板与数据保护

自动复制回退默认关闭，必须在本机设置页确认风险，仅本次运行有效。原剪贴板为空或仅含受支持的文本格式时，程序尽量完整保存并恢复。原内容含 HTML、RTF、图片、文件、OLE 或其他复杂格式时，授权后仍可尝试复制，但不会备份或恢复这些内容，原内容可能被覆盖且无法恢复。开启前请确认剪贴板没有必须保留的重要内容；不愿承担风险时保持回退关闭，使用目标应用的手动复制功能。

模拟复制会操作 Windows 共享剪贴板。访问失败、快照数据异常、敏感控件、目标切换或来源不可信时仍会拒绝；不会自动换键重试。异步复制或其他程序同时写入时，可能跳过文本恢复以避免覆盖新内容；恢复失败不能保证原内容完整保留。请避免在敏感内容中启用，不能将本功能视为任意剪贴板格式的无损备份，也不保证所有软件支持自动划词。

高风险剪贴板、设置保存、备份恢复、自启修改仅使用专用数据并另行确认；不以破坏正式数据为代价验收。包未签名，SHA256 仅用于内容校验；EXE 摘要见 HASH.txt，ZIP 摘要见同名 .sha256 文件。
