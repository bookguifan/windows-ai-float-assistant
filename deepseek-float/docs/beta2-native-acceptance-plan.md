# Beta.2 普通 Release 验收清单

使用 `pnpm release` 新构建的 `release/deepseek-float.exe`，不依赖开发服务器。
记录源码 SHA、EXE SHA256、Windows/WebView2 版本即可；一次会话完成多项功能。
启动和涉及数据的操作须在获得相应授权后执行。本次流程修改没有启动 EXE。

| 项目 | 结果 | 简要说明 |
| --- | --- | --- |
| 启动、页面渲染与 UI Ready | NOT TESTED | 可交互的球页/明确 ready 信号；只有 HWND 不算通过 |

填写 PASS、FAIL 或 NOT TESTED，并给出一行原因。历史候选的结果不能代替本次候选。
不必每个功能再跑一次 `beta2-isolation`；它是可选的诊断能力，路径/安全不变量仍在 CI 验证。
PR #6 的隔离诊断代码尚未合并，本流程不依赖它，也不将诊断构建作为普通功能门槛。

## 数据操作

- 剪贴板：只在明确授权且剪贴板已换成专用测试内容后操作；本次没有读写剪贴板。
- 设置：默认只打开/关闭。无法保证恢复真实偏好时，不执行保存测试并注明原因。
- 备份恢复：只用测试配置和临时目标；无法确保不触及正式数据时跳过，不把它当作所有功能的启动前置条件。
- 自启：普通烟测无需修改；专项测试前记录原始状态，完成后还原。
- 可使用本机现有测试账户保护数据，但不要求安装 VM、Sandbox 或建立多套开发环境。
  普通构建使用 Windows Known Folder，改 `LOCALAPPDATA` 不保证数据隔离。

## 放行

当前提交 CI 通过、普通 Release 可启动并 UI Ready、主要功能可用且正常退出，
没有确认的严重数据丢失，包内无敏感信息且必要许可完整，才可发布。
Issue #2 可保持开放；若当前候选稳定复现严重故障，则阻止发布并记录复现步骤。
未能安全执行的数据操作明确记 NOT TESTED，不伪造通过，不要求完成历史全部测试矩阵。
